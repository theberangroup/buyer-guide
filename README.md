# Homebuyer Guide — read-only edition

Kristin Beran Krupp / The Beran Group. Static HTML, no build step, no stored data.

- `index.html` — the whole guide (styles and script inline).
- `assets/` — logos, headshot, self-hosted fonts (Manrope, Playfair Display).
- `assets/cvr-310-buyer-agreement.pdf` and `assets/cvrmls-area-map.pdf` — **add these two PDFs**; the guide links to them.
- `CNAME` — custom domain for GitHub Pages. Add a DNS CNAME record `buyer-guide → theberangroup.github.io`, then enable "Enforce HTTPS" in the repo's Pages settings.

The calculator, offer builder and glossary search work in-page but reset on every visit by design.
